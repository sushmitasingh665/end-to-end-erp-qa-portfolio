# TMSLite — Loading

## Loading workflow
1. Locate the trip using the synthetic Trip ID and relevant date.
2. Confirm that the location is available and activated where first-time setup requires it.
3. Load the planned quantity into the correct vehicle compartments.
4. Confirm loading and verify the resulting acknowledgement/confirmation.
5. Validate the related Bill of Lading/loading document output where configured.
6. Verify the Salesforce order status and Navision loading-processing record.

## QA checks
- Correct trip and location.
- Correct product and quantity.
- Compartment allocation.
- Loading confirmation updates.
- Missing/inactive location and insufficient inventory/setup negative scenarios.

Do not publish real user email addresses, document files, trip IDs or customer details.
