# TMSLite — User Profile Location Setup

The required company location must be available in the user's TMSLite profile before trip/loading work is performed.

## Steps

1. Launch TMSLite.
2. Open the user profile.
3. Search for the required company location.
4. Select/add the correct location to the profile.
5. Save the profile.
6. Reopen the profile and verify that the location is listed and available.

**Expected result:** The required location is associated with the user's profile and can be selected when accessing trips for that location.
