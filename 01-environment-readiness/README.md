# Environment Readiness

## Purpose
Document the checks performed before functional and end-to-end testing begins in a fresh test environment.

## Readiness areas
- Confirm environment access and configuration details with the authorized project/development team.
- Verify the required company configuration in connected applications.
- Confirm that Salesforce and Navision are aligned to the intended company/environment.
- Check that required modules, users and role permissions are available.
- Confirm integrations and synchronization routes are enabled for the test scope.
- Record prerequisites, dependencies and known blockers.

## Security
Never publish environment URLs, tenant IDs, credentials, customer information or internal identifiers.

## Planned artefact
An environment-readiness checklist with synthetic examples and clear Pass / Fail / Blocked criteria.
