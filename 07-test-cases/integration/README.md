# Integration Test Cases

Focus on source-to-destination data movement and cross-application status consistency.

Areas include:
- Salesforce customer/order data.
- Navision product and location synchronization.
- Bulk/package product-specific logistics synchronization.
- Navision order release to WindDMS planning.
- WindDMS Trip ID visibility in Salesforce.
- TMSLite loading acknowledgement and confirmation.
- WindDMS delivery confirmation and Navision staging records.

Record the source, destination, trigger, expected payload/business fields, processing status and reconciliation checks. Use synthetic values only.
