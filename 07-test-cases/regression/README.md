# Regression Test Cases

Maintain a reusable regression set around business-critical workflows:
- Customer setup and order creation.
- Prepayment and credit control.
- Product/location synchronization.
- SKU and inventory.
- Location/contract-dependent pricing.
- Bulk logistics and package processing distinction.
- Loading, delivery, invoice and consignment transfer.
- Procurement approvals and payment advice.

Record the requirement/defect that triggered the regression, impacted applications, test data and result. Do not claim a regression run unless it was executed.
