# Negative Test Cases

Examples of negative coverage to design:
- Prepayment order without payment.
- Credit order with insufficient credit and no approval.
- Invalid or inactive product/location setup.
- Package product incorrectly sent to logistics.
- Missing inventory/setup dependency during posting.
- Invalid delivery date or product time-window gap.
- Unauthorized approval or incomplete mandatory data.

These are scenario ideas, not executed results. Define expected behaviour from the confirmed requirement before finalizing each test case.
