# Test Data and Execution

## Test-data principles
- Use fictitious customers, products, locations, vehicles, quantities, prices and transaction IDs.
- Separate customer data created in Salesforce from product/location data created in Navision.
- Identify source application and expected destination for each synchronized record.
- Maintain distinct datasets for prepayment/credit customers and bulk/package products.
- Do not copy production or client data into this public repository.
