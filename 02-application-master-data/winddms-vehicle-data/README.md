# WindDMS — Vehicle Master Data

Vehicle records are maintained in WindDMS. The related transporter/vendor is created in Navision; its vendor reference is used as the haulier reference in WindDMS.

## Setup information
- Company association
- Haulier association
- Vehicle number
- Compartment configuration

## QA checks
- Verify the vehicle is associated with the intended company and haulier.
- Verify vehicle number and compartment details.
- Confirm that the vehicle is available for the relevant planning scenario.

Use fictitious company, haulier and vehicle references in all public examples.
